# Print Design

The two executable variants use the same in-app UI font sizes. Only the printed page font sizes differ.

## Display.exe

| Area | Font size |
|---|---:|
| Body | 6.5pt |
| Page header | 9pt |
| Description | 4.5pt |
| Item Code | 7.5pt |

## Display_big.exe

| Area | Font size |
|---|---:|
| Body | 8.5pt |
| Page header | 11pt |
| Description | 6.5pt |
| Item Code | 9.5pt |

## Notes

- `Display_big.exe` is the print-large variant.
- Both variants are packaged with 32-bit Python.
- Product unit printing uses the item's unit name, such as `PC`, `DZ`, `PK`, `BX`, or `BG`, when the manual `Unit` quantity is used.
